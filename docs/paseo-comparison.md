# Paseo comparison

This comparison covers a developer working with installed agents from a phone and a desktop. The reference is [Paseo at 9eab3b2](https://github.com/getpaseo/paseo/tree/9eab3b278f7a5288f1aed5b71f2889ffc3ecde61).

| Workflow | Gap found in Pulsar | Change |
| --- | --- | --- |
| Choose a model and reasoning level | Pulsar read the provider's mode but dropped the model and effort controls. | The shared ACP adapter reads the provider's choices. The composer applies them and checks the selection returned by the provider. **New agent** can confirm both settings before sending the first prompt in a managed ACP session. Antigravity, Claude ACP, OMP and OpenCode changed and restored both settings in disposable sessions. [Paseo provider tests](https://github.com/getpaseo/paseo/blob/9eab3b278f7a5288f1aed5b71f2889ffc3ecde61/packages/server/src/server/agent/providers/acp-wrapper-smoke.test.ts) |
| Read a tool call | Some agents deliver the path and arguments after the first event. Pulsar dropped those details, including on child calls. | Later updates fill the same tool call. Parent and child transcripts share the normalization. [Paseo tool details](https://github.com/getpaseo/paseo/blob/9eab3b278f7a5288f1aed5b71f2889ffc3ecde61/packages/plugin/src/server/acp-internal/tool-call-detail.ts) |
| Return to a closed conversation | A saved link worked, but search missed closed sessions. Sessions that closed before anyone opened them could disappear. | Search by name, project or harness on this machine and compatible peers. Local matches appear while peers respond. Opening the result displays its transcript and any recorded usage. [Paseo archive search](https://github.com/getpaseo/paseo/blob/9eab3b278f7a5288f1aed5b71f2889ffc3ecde61/packages/app/src/archived-workspaces/internal/use-archived-workspace-search.ts) |
| Switch chats while composing | Navigating away could discard text, file references and mentions. | A draft for a specific recipient survives navigation and reload in the same browser tab. Sending an earlier draft preserves later edits. Broadcast drafts stay with their chosen scope. [Paseo draft storage](https://github.com/getpaseo/paseo/blob/9eab3b278f7a5288f1aed5b71f2889ffc3ecde61/packages/app/src/stores/draft-store/persistence.ts) |
| Discuss a change with an agent | The file viewer and diff viewer showed the code, but the operator had to copy its location and context by hand. | Add selected lines to the conversation draft. Diff selections keep the side and path so the agent can identify removed lines. [Paseo diff sharing](https://github.com/getpaseo/paseo/blob/9eab3b278f7a5288f1aed5b71f2889ffc3ecde61/packages/app/src/git/diff-sharing.ts) |

Paseo also lets you collect review comments and choose a different agent to receive them. Pulsar adds selected source to the draft for the conversation where you opened the file. Use **Copy quote** to take the same path, range and diff side into another agent’s draft. [Paseo review feedback](https://github.com/getpaseo/paseo/blob/9eab3b278f7a5288f1aed5b71f2889ffc3ecde61/packages/app/src/review/feedback/index.ts)

Pulsar covers 37 of the 45 Paseo providers in scope. The comparison identified three working additions: Vercel fx, Hermes Agent and Gajae Code. Each received a message through Pulsar, replied from a local model, and connected to the Pulsar MCP server. The eight remaining are Agoragentic, Autohand, CodeWhale, Hoplite, Minion Code, Nova, TRAE CLI and VTCode. CodeWhale, for example, rejected the required MCP server at startup. [Qualification and versions](acp.md) · [Paseo catalog](https://github.com/getpaseo/paseo/blob/9eab3b278f7a5288f1aed5b71f2889ffc3ecde61/packages/app/src/data/acp-provider-catalog.ts)

Both projects support separate worktrees for parallel tasks, agent control through MCP, and mobile review. Pulsar already provides passkey approvals, a message queue with edit and cancel, file mentions, voice dictation, and cross-machine delivery. [Pulsar app](app.md) · [Pulsar delivery](delivery.md) · [Paseo parallel development](https://paseo.sh/docs/parallel-development)

Paseo also ships a plugin marketplace, shared team automations, an embedded browser, and a public relay. Those would expand Pulsar into new products or change how devices connect. Pulsar's current scope uses installed harnesses and a private mesh. Standalone Antigravity sessions still depend on the controls available in the native terminal. See the adapter table for the differences between an attached terminal and a Pulsar-managed provider. [Adapters](adapters.md) · [Private mesh](federation.md) · [Paseo](https://paseo.sh/)
